## 🌌 Acerca del proyecto

**NASA SPACE** es un proyecto de aplicación multiplataforma desarrollado utilizando Flutter, con el propósito de ofrecer una experiencia tecnológica relacionada con el entorno espacial.

El proyecto busca integrar herramientas y funcionalidades que permitan construir una aplicación moderna, intuitiva y adaptable a diferentes dispositivos.

Actualmente se encuentra en desarrollo.

## 🎯 Objetivos

- Desarrollar una aplicación multiplataforma.
- Implementar una interfaz moderna e intuitiva.
- Integrar servicios y herramientas externas.
- Facilitar el acceso a funcionalidades desde diferentes dispositivos.
- Aplicar buenas prácticas de desarrollo de software.

## 🛠️ Tecnologías utilizadas

| Tecnología | Descripción |
|---|---|
| Flutter | Framework de desarrollo multiplataforma |
| Dart | Lenguaje de programación |
| Android | Plataforma móvil |
| iOS | Plataforma móvil |
| Web | Aplicación web |
| Windows | Aplicación de escritorio |

## 📦 Dependencias principales

- `share_plus`: funcionalidades para compartir contenido.
- `jitsi_meet_wrapper`: integración con reuniones mediante Jitsi.
- `url_launcher`: apertura de enlaces externos.
- `shared_preferences`: almacenamiento de preferencias locales.

## ⚙️ Instalación y ejecución

### 1. Clonar el repositorio

```bash
git clone https://github.com/AxelAndr123456789/NasaSpace.git
```

### 2. Ingresar al proyecto

```bash
cd NasaSpace
```

### 3. Instalar dependencias

```bash
flutter pub get
```

### 4. Ejecutar la aplicación

```bash
flutter run
```

### 5. Generar APK para Android

```bash
flutter build apk --release
```

## 💻 Requisitos

- Flutter SDK.

- Android Studio o Visual Studio Code.
